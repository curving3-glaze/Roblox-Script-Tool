## FAQ

### What is XCutors?

XCutors is a Windows desktop application that bundles several popular Roblox executors and a universal script loader called xcutorsLoader, allowing you to run Lua scripts for game customization.

### Which executors are included?

XCutors includes Volt, Synapse Z, Potassium, and Wave, along with our own xcutorsLoader for unified script management.

### Is XCutors free to use?

XCutors is free to download and use. Some included third-party executors may have their own licensing terms; please check each executor's documentation.

### What are the system requirements?

XCutors requires Windows 10 or later, a stable internet connection, and the latest version of Roblox installed on your system.

### How do I update XCutors?

XCutors features an automatic update checker. You can also manually check for updates from the Settings tab or download the latest release from GitHub.

### Can I use my own Lua scripts?

Yes! Use the xcutorsLoader or the script input area to load any custom Lua script. You can also save frequently used scripts to your favorites.

### Why is my executor not connecting?

Make sure Roblox is running, your executor version is up to date, and no anticomponent software is blocking the connection. Check the error logs in the Troubleshooting tab for more details.

### Is XCutors safe from components?

XCutors itself is clean and open-source on GitHub. We recommend downloading only from official releases and scanning files with your preferred anticomponent before use.
